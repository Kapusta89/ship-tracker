# Что делать при ошибках

Короткая инструкция на случай, если приложение или бот не открылись, молчат
или показывают непонятную ошибку. Всё, что нужно, уже лежит в папке проекта.

## Три шага при любой проблеме

1. Запустите **`check.bat`** (в папке `ship_tracker`). Он проверит Python,
   tkinter, пакеты, настройки, запись в базу и сеть и откроет отчёт
   `data/diagnose.txt`.
2. Посмотрите **`data/errors.log`** — там traceback последнего сбоя приложения.
   У бота свой журнал: **`data/bot_run.log`**.
3. Если сами не разобрались — пришлите `data/diagnose.txt` и `data/errors.log`.
   В этих файлах нет ключей, только их наличие.

Отдельный журнал установки окружения: `%LOCALAPPDATA%\ShipTracker\env.log`.

---

## «Окно мигнуло и закрылось» / приложение не открывается

1. Запустите из командной строки, текст ошибки останется на экране:

       cd /d "путь\к\проекту\ship_tracker"
       run.bat

2. Прочитайте последнюю строку в `data/errors.log`.
3. Запустите `check.bat` и посмотрите пункт «Итог».

## Bat-файл пишет «... is not recognized as an internal or external command»

Это переводы строк (LF вместо CRLF) — так бывает, если папку копировали не
через git. Лечится переустановкой файлов из репозитория:

    git rm --cached -r .
    git reset --hard

или проще: удалить папку и клонировать заново. В репозитории это закреплено
`.gitattributes` (`*.bat text eol=crlf`), поэтому при `git pull` файлы приходят
уже правильными.

## «На этом компьютере не найден Python 3»

1. Скачайте Python 3.12 с <https://www.python.org/downloads/windows/>.
2. При установке отметьте **Add python.exe to PATH** и **tcl/tk and IDLE**.
3. Закройте и откройте командную строку, проверьте `py -3 --version`.
4. Запустите `run.bat` снова.

## «Python установлен без библиотеки tkinter»

Окно открыться не может — установщик был без tcl/tk. Переустановите Python
с python.org с галочкой **tcl/tk and IDLE**. Боту tkinter не нужен: `bot.bat`
работает и без него.

## «Версия Python слишком старая»

Нужен 3.9 или новее, лучше 3.11–3.13. Новый Python можно ставить рядом со
старым, удалять прежний не нужно.

## «Не удалось установить пакеты из requirements.txt»

1. Проверьте интернет, VPN/прокси и антивирус.
2. Откройте `%LOCALAPPDATA%\ShipTracker\env.log` и найдите первую строку
   с `ERROR` — там настоящая причина (нет сети, сертификат, места на диске).
3. Повторите `setup.bat`. Скрипт сам пробует отдельное окружение, а если не
   вышло — системный Python с `--user`.

Полный сброс окружения (безопасно, папка пересоздастся):

    rmdir /s /q "%LOCALAPPDATA%\ShipTracker\venv"
    setup.bat

## «Не удалось создать отдельное окружение»

Обычно мешают антивирус или нехватка места. Проверьте свободное место на
диске `C:`, добавьте папку `%LOCALAPPDATA%\ShipTracker` в исключения
антивируса и повторите `setup.bat`.

## Карта пустая, судов нет

1. Вкладка **«Подключение»**: у каждого канала свой статус и кнопка
   «Проверить». «На связи» — канал работает.
2. Нет ключа AISStream — карта наполняется снимком района и Open Waters,
   это нормально, но медленнее. Ключ бесплатный: <https://aisstream.io>.
3. Если статусы зелёные, а судов нет — у портов сейчас нет покрытия AIS;
   список пополняется по мере появления судов.
4. Вкладка **«В море»** показывает суда со свежей позицией вне портов,
   вкладка **«Все суда»** — вообще всех, включая суда без сигнала.

## Бот не отвечает

1. Бот держит `data/bot.lock`, чтобы две копии не отвечали в один чат.
   Закройте лишние окна бота.
2. Если бот упал и файл остался — удалите `data/bot.lock` (только когда ни
   один бот не запущен) и запустите `bot.bat` снова.
3. Проверьте `data/bot_run.log`: там видно, принят ли токен и идут ли команды.

## Ошибки источников

| Сообщение | Что делать |
|---|---|
| `AIS-catcher: страница без таблицы Expected` | Сайт отдал заглушку; подождите цикл обновления (1 ч) или нажмите «Проверить» на вкладке «Подключение» |
| `GFW: 401/403` | Токен Global Fishing Watch истёк или скопирован с мусором — вставьте заново на вкладке «Подключение» |
| `GFW: 422` | Ошибка параметров запроса; обновите программу до последней версии |
| `VesselFinder: Invalid Userkey!` | Ключ неверный или закончился триал — отключите канал в «Сервисах» |
| `MyShipTracking: кредиты триала закончились` | Бесплатные запросы кончились, канал можно отключить |
| `Поток AIS прерван: 429` | Слишком частые подключения; программа сама выждет и переподключится |
| `Снимок района недоступен` | Нет сети или сайт лёг; данные останутся в базе, следующий цикл повторит запрос |
| `Goradar (карта судов): 403` | Сайт временно закрыл доступ с этого адреса; поток сам повторит через 15 мин, остальные каналы работают |
| `MarineTraffic.live (карта судов): ошибка` | Сайт сменил адрес JSON — обновите программу; район при этом виден по снимку и Goradar |
| `Источники: Oceanook → Security Check` | Защита от роботов: позиции не читаются, откройте сайт глазами |
| `Источники: FleetMon → DNS` | Домен не открывается с этого компьютера (провайдер или фильтр); канал не нужен — FleetMon только по платному ключу |

## Приложение и бот одновременно

AIS принимает только один процесс (файл `data/feed.lock`), второй читает ту же
базу. Если в «Подключении» написано «принимает другой процесс» — так и должно
быть. Чтобы данные шли из одного места, запускайте оба на одном компьютере.

## OneDrive

Проект можно держать в OneDrive: окружение теперь лежит вне папки проекта
(`%LOCALAPPDATA%\ShipTracker\venv`), поэтому ничего не ломается при
синхронизации. Единственное ограничение — не запускайте приложение
одновременно на двух компьютерах с одной и той же базой: файл базы будет
конфликтовать при синхронизации.

## Обновление до новой версии

    git pull

Если папка была скопирована, а не склонирована, скачайте архив заново и
замените файлы, сохранив папку `data`. После обновления запустите `check.bat`.
Версия видна в заголовке окна и на вкладке «Подключение».
