# Ship Tracker для телефона

Мобильная версия работает так: на компьютере запущен Ship Tracker и рядом
`shop_tracker_mob.exe`, телефон в той же Wi-Fi сети показывает те же данные.
Своей базы на телефоне нет — поэтому цифры на телефоне всегда такие же
свежие, как на компьютере. Ключи и подключения к источникам данных задаются
в версии Ship Tracker, которая запускается через `run.bat`.

## Что установить

1. Скопируйте `ShipTracker.apk` на телефон (кабель, облако, Telegram «себе»).
2. Откройте файл на телефоне и разрешите установку из этого источника.
   Android 5.0 и новее.
3. На компьютере запустите `shop_tracker_mob.exe` (он же поднимает сервер).
4. Откройте Ship Tracker на телефоне. Приложение само ищет компьютер в Wi-Fi.
   Если не нашло — введите адрес, который показан в окне `shop_tracker_mob.exe`,
   например `http://192.168.1.35:8080`.

Экран настройки адреса появляется сам, если компьютер выключен, приложение
не запущено или телефон в другой сети. Кнопка «Найти компьютер в сети»
запускает поиск ещё раз.

## Что внутри приложения

Вкладки те же, что в настольной версии:

- **Радар** — карта портов и судов за 12 часов, поиск и отбор (все, в ходу,
  у порта, закреплённые), карточка судна с историей позиций и стоянками.
- **В море** — суда, связанные с нашими портами, с отбором по порту,
  расстоянием и расчётным прибытием.
- **4 дня** — план по судам, идущим в наши порты: путь, стоянка (медиана
  наших визитов в порт) и «всего до выхода».
- **Все суда** — все суда в рабочем районе, идущие к нам, и где они будут
  через день, два и четыре (порт по курсу помечен «по курсу»).
- **Стоянки** — кто стоит сейчас и история стоянок.
- **Связь** — состояние каналов и наличие ключей (ключи задаются только
  в варианте через `run.bat`).

## Сборка APK без Gradle

Нужны JDK 17 (`JAVA_HOME`) и Android SDK с `build-tools;34.0.0` и
`platforms;android-34` (`ANDROID_HOME`).

```bash
cd shop_tracker_mob/android
JAVA_HOME=... ANDROID_HOME=... bash build_apk.sh
```

Скрипт собирает `shop_tracker_mob/ShipTracker.apk` и подписывает его ключом
`$ANDROID_HOME/shiptracker.jks` (создаётся при первой сборке). Промежуточные
файлы лежат во временной папке `$ANDROID_HOME/apkstage`, потому что `aapt2.exe`
не понимает кириллицу в пути.

## Пересобрать сервер

```bash
python -m PyInstaller --noconfirm --clean --onefile --console --name shop_tracker_mob \
  --distpath "shop_tracker_mob" --workpath "build_mob" --specpath "build_mob" \
  "shop_tracker_mob/shop_tracker_mob.py"
```
