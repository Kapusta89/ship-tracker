# Версии приложений Ship Tracker

Одна и та же доработка вносится во все приложения, к которым она относится,
и каждое получает свою следующую версию — чтобы по номеру было видно, что
где стоит.

| Приложение | Файл | Версия | Собрано |
|---|---|---|---|
| Ship Tracker (исходное, Python) | `ship_tracker/ship_tracker.py` | **2026.12.71** | 2026-11-20 |
| Ship Tracker для Windows | `ship_tracker.exe/ship_tracker.exe` | **2026.12.71** | 2026-11-20 |
| Ship Tracker Mobile (телефон) | `shop_tracker_mob/shop_tracker_mob.exe` | **2.4.0** | 2026-11-21 |
| Ship Tracker APK (Android, Wi-Fi) | `shop_tracker_mob/ShipTracker.apk` | **2.0.1** (201) | 2026-11-20 |
| Ship Tracker Android (автономное) | `shop_tracker_android/ShipTracker-autonomous.apk` | **3.3.0** (330) | 2026-11-21 |

Версия видна: в заголовке окна (обе настольные копии), на вкладке
«Подключение» рядом с путём к папке, а в мобильной версии — в подвале
страницы и в ответе `/api/ships` (`version`).

## Правило обновления

1. Изменение делается в исходнике `ship_tracker/`.
2. Номер версии поднимается у каждого затронутого приложения и записывается
   строкой в журнал ниже; exe пересобирается из того же исходника, поэтому
   версия исходника и exe совпадают. Если доработка касается телефона, она
   повторяется в `shop_tracker_mob/` (страница `mobile_page.py` и сервер
   `shop_tracker_mob.py`) и получает свой номер.
3. В таблице выше обновляются версия и дата сборки.

## Где живут ключи

Ключи и токены источников данных заданы только в варианте, который
запускается через `run.bat` (`ship_tracker/run.bat`, файл
`ship_tracker/data/config.json`). Собранная копия `ship_tracker.exe`
поставляется с пустыми полями подключения: пользователь вводит свои ключи сам.
Собранная копия показывает об этом подсказку на вкладке «Подключение».

### 2026-11-21 (автономное приложение для Android)

- Папка `shop_tracker_android/` — самостоятельная версия для телефона:
  Python 3.11 внутри APK (Chaquopy), интерфейс в WebView, локальный сервер на
  `127.0.0.1:8080`. Компьютер и Wi-Fi не нужны: приложение само тянет AISStream
  и сайты и пишет всё в свою базу на телефоне; вкладки те же, что настольной
  версии («Радар», «В море», «Прогноз 4 дня», «Прогноз всех судов», «Стоянки»,
  «Подключения»).
- Код данных и расчётов не переписан: в APK лежат модули настольной версии
  (`core.py`, `store.py`, `services_feed.py`, `services_optima.py`, `forecast.py`
  и остальные), копируются скриптом `sync_python.sh`. Пути базы, кэшей и
  журналов переносятся в память приложения (`android_main._patch_paths`).
- Ключи не зашиты в APK: при первом запуске открывается экран настроек, ключ
  AISStream вводится вручную и сохраняется в памяти приложения; шестерёǅнка
  в шапке открывает этот экран позже. После сохранения сбор данных
  перезапускается сам.
- Сборка: `build_apk.sh` (JDK 17, Android SDK 34, Gradle 8.7). Готовый файл —
  `ShipTracker-autonomous.apk` (18 МБ, package `com.kapusta.shiptracker`,
  debug-подпись, arm64-v8a + armeabi-v7a).
- Проверено: `py_compile` всех модулей; содержимое APK (рантайм Python 3.11,
  `requests`/`websockets`, все 20 модулей); запуск того же кода на ПК
  (`preview_host.py`) — сервер отвечает, сбор данных идёт, все API-вкладки
  отдают данные. Запуск на телефоне не проверялся: устройства нет.

### 2026-11-20 (2026.12.71)

- **2026.12.71** — четыре новых источника, в первую очередь в варианте через
  `run.bat` (все — на вкладке «Подключение»):
  **Maritime Optima** (`mo`) и **ShipAtlas** (`sa`) — публичные карточки судов
  без входа и без ключа: паспорт (флаг, тип, постройка, LOA, ширина, осадка,
  позывной) и рейс (куда идёт, район, навигационный статус, свежесть AIS).
  Карточка одна на оба канала, с кэшем на 30 минут; тип и размеры идут в базу,
  назначение записывается только там, где AIS его не сообщил, а район и статус
  складываются в `data/shipatlas.json`. **MarineLink** (`mlink`) — открытый
  справочник судов по типам: заполняет тип у судов, где своего нет (сверка по
  точному имени). **ShipNext** (`sn`) — каталог судов по токену аккаунта,
  выключен по умолчанию: `/api/v1/vessels` без токена отвечает 401.
  Публичных данных о позициях у этих источников нет — как и раньше, позиции
  дают AIS-потоки, карты и ShipFinder; новые каналы уточняют паспорт и рейс.
